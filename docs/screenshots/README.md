# Zero-Distractions Screenshots

Drop your real Android or PWA screenshots in this folder using the suggested filenames below, then link them inside the root [`README.md`](../../README.md#screenshots) gallery table.

## Recommended Filenames

| File | Screen to Capture |
| :--- | :--- |
| `home-dial.png` | Home **Dial** tab (Classic UI with scrubbable timer, `#Hashtag` selector & 4-Bag switcher) |
| `the-void-standard.png` | **The Void** lock screen (Pixel System Clock, Inverted Countdown card & Bag apps) |
| `the-void-work-bag.png` | **The Void** with **Work Bag** active (centered giant `#HASHTAG` spotlight + docked Bag at bottom) |
| `theme-studio.png` | **Settings & OS -> Themes** (AMOLED / Paper Kindle / Matte Studio presets + Interface Style switcher) |
| `insights-profile.png` | **Insights** heatmaps / achievement badges or **Profile** live theme switcher & pledges |
| `backup-cloud.png` | **Settings -> Backup and Restore Everything** (`.zbak` auto-sync, One-Tap Save, Cloud Upload & reminder timer) |
| `bespoke-mode.png` | **Bespoke Minimalist** mode showcase (optional extra comparison shot) |

## Tip

- Phone screenshots captured in portrait (`~9:20` aspect ratio) automatically size cleanly inside the 3-column Markdown table in the root [`README.md`](../../README.md).
- On GitHub's web editor, you can also open [`README.md`](../../README.md), edit it directly, and **paste (`Ctrl + V`) or drag-and-drop** screenshots straight into the table cells without uploading files manually.
