## 3. Dynamic Tokens & Utility Classes (Liquid Glass Pro 60FPS)
- **Dynamic CSS Variables (`:root`):**
  - `--liquid-accent-vibrant`: Active Theme Studio accent hex (e.g. `#00F2FE`, `#F59E0B`, `#34D399`, `#A78BFA`).
  - `--liquid-accent-tint`: Automatically computed luminous tint `color-mix(in srgb, var(--liquid-accent-vibrant) 28%, #ffffff)`. Never black or dark slate.
  - `--liquid-accent-glow`: Luminous glow `color-mix(in srgb, var(--liquid-accent-vibrant) 50%, transparent)`.
  - `--liquid-accent-soft-glow`: Ambient reflection `color-mix(in srgb, var(--liquid-accent-vibrant) 22%, transparent)`.
- **Core Utility Classes:**
  - `.liquid-glass`: Authentic card surface with backdrop blur (28px), saturation (180%), specular top border highlight, and dynamic inner refraction.
  - `.liquid-track`: Recessed glass track for segmented controls and progress bars.
  - `.liquid-pill-active`: 3-way luminous gradient (`#ffffff 0%` -> `var(--liquid-accent-tint) 42%` -> `var(--liquid-accent-vibrant) 100%`) with deep obsidian text (`#07040d`, `font-weight: 800`).
  - `.liquid-pill-inactive`: Frosted glass pill with smooth hover transition.
  - `.liquid-gliding-pill`: Hardware-accelerated gliding indicator for segmented tab switchers.
  - `.liquid-dial-outer`: Circular timer dial outer ring refracts active Theme Studio color.
  - `.liquid-shimmer-bar`: Specular shimmer sweep progress bar.
  - `.liquid-dock`: Floating navigation bar with rounded-[2rem] geometry.
  - `.liquid-dock-item-active`: Active bottom navigation tab item with top highlight rim and glowing accent fill.
